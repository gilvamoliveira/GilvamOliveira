## Featured projects

### ForumHub — forum REST API

Forum topic API built with Java 17, Spring Boot, Spring Data JPA, MySQL and Flyway. It has DTOs, validation, migrations and topic creation that rejects duplicate title and message. Login issues a JWT; token validation on requests is still being implemented, and the README says so.

**My role:** ONE challenge — domain modelling, endpoints, migrations and per-environment configuration.

`Java` `Spring Boot` `JPA` `MySQL` `JWT` · [Source](https://github.com/GilvamOliveira/forumhub)

### Client Registry — API + interface

Client registry with a REST API in Node.js and SQLite, server-side pagination, search, filters and sorting. Token authentication is optional, there is per-route rate limiting, restricted CORS and 23 automated tests running in CI. The same interface works without the back end, falling back to `localStorage` in the static demo.

**My role:** I built the base from the course project and evolved the API, the tests and the deploy setup.

`JavaScript` `Node.js` `SQLite` `REST` `Docker` · [Demo](https://gilvamoliveira.github.io/client-registry/) · [Source](https://github.com/GilvamOliveira/client-registry)

### LiterAlura — book catalogue

Catalogue that queries the Gutendex API and stores books and authors with JPA and PostgreSQL, allowing search by title, author listing and filtering by language.

**My role:** implementation of the ONE challenge.

`Java` `Spring Boot` `JPA` `PostgreSQL` · [Source](https://github.com/GilvamOliveira/LiterAlura)

### Meteoro de Lógica

Study platform with the 84 exercises from the Manzano and Faccat workbooks. Solutions appear side by side in VisualG and JavaScript, and a VisualG interpreter written in JavaScript runs the programs in the browser. It has 23 tests and CI.

**My role:** I solved all 84 exercises in both languages; the interface was built with AI assistance.

`JavaScript` `VisualG` `HTML` `CSS` · [Demo](https://gilvamoliveira.github.io/meteoro-de-logica/) · [Source](https://github.com/GilvamOliveira/meteoro-de-logica)
